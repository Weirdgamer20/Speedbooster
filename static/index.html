How to use in Windows:

  1. In Windows Search, type Proxy Settings.
  2. Turn ON "Use a proxy server".
  3. Set IP address: 127.0.0.1 and Port: 8080.
  4. Or in IDM: configure proxy to 127.0.0.1:8080 with 8-16 connections.
